# Orivo — Product Requirements & Build Log

## Vision (current)
Executive Decision Intelligence Platform. Premium, private, dark-first mobile app that helps founders, CXOs, CEOs, investors, and senior professionals make better decisions. Underlying engines (Vedic astrology, numerology, vaastu, AI) are translated entirely into business language. Aesthetic target: Bloomberg + Notion + Linear + Apple Health + Headspace + Mercury.

Never mystical. Never spiritual. Never fortune-telling.

## Stack (as built — Jun 29, 2026)
- **Mobile/Web**: Expo (React Native) + Expo Router + Expo Web on port 3000
- **Backend**: FastAPI (Python) on port 8001
- **DB**: MongoDB (motor)
- **Auth**: Phone OTP, JWT. Dev-mode OTP bypass `123456`; Twilio plug-in deferred
- **Payments**: Stripe Checkout via `emergentintegrations`
- **LLM**: Claude Sonnet 4.5 via Emergent Universal Key — for personalized reports, Daily Brief, and the new AI Advisor chat
- **Geocoding**: OpenStreetMap Nominatim
- **Astrology engine**: deterministic rule engine seeded by DOB + time + place (kept internal; never surfaced to UI)

## User personas
1. Founder / CEO
2. C-suite executive
3. Investor / managing partner
4. Senior professional

All time-poor, privacy-first, skeptical of "mystical" branding.

## Core data models (MongoDB)
- `users` — phone, name, role, businessName, industry, birth, tier, referralCode, onboarded
- `reports`, `daily_outlooks`, `daily_briefs` (new) — Decision Index + Phase + Window + AI brief cached per user+date
- `advisor_messages` (new) — chat history with role/content/sessionId
- `decisions` (new) — saved decisions ledger
- `credits_ledger` (balance in seconds; expiry 90 days)
- `task_completions`, `bookings`, `payment_transactions`, `notifications`, `otp_sessions`
